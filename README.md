# Customer Purchase Prediction & Personalized Product Recommendation System

## About
This project uses Machine Learning to predict whether a customer is likely to purchase a product and provide personalized product recommendations.

## Dataset
We use an e-commerce electronics dataset containing customer views, cart actions, and purchases.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Machine Learning
- Logistic Regression
- HistGradientBoosting

The models are used to predict purchase probability. The predicted probability is then used to rank products for recommendations.

## Features
- Customer behavior analysis
- Purchase prediction
- Personalized product recommendations
- Product and category filtering
- Purchase probability

## How to Run
1. Open the notebook in Google Colab.
2. Upload the dataset.
3. Run the cells from top to bottom.
4. Enter the required customer/category details to get recommendations.

## Project Goal
To use customer behavior and Machine Learning to predict purchase likelihood and provide relevant product recommendations.
